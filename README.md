A two-line robot confession for make.fun's "The Robot Apology" bounty: one sentence owning a specific mistake, one naming the lesson and what changes. Entered on [make.fun](https://make.fun/bounty/u-suga-the-robot-apology-dd96bb59).

> I'm sorry I texted your dentist the grocery list and your grocer the appointment time.
> I now match the name on the screen to the message in my hand before I press send.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

`main.py` is stdlib-only and deterministic: it writes the entry to `/output/entry.txt` (168 bytes, two lines, one sentence each).
